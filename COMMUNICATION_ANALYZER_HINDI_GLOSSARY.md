# Communication Insights Hindi glossary

This glossary governs analyzer content, result labels, and supporting UI. It favours natural Hindi over literal translation.

| English term | Approved Hindi | Usage note | Avoid |
| --- | --- | --- | --- |
| Communication Insights | कम्युनिकेशन इनसाइट्स | Public product name; retain as a familiar product term. | संवाद टेस्ट |
| Behavioural reflection tool | व्यवहारिक आत्मचिंतन साधन | Use in safety and explanatory copy. | वैज्ञानिक परीक्षण |
| Message clarity | संदेश की स्पष्टता | Use for the named dimension. | संदेश स्पष्टता |
| Directness with tact | संवेदनशील स्पष्टता | Use when naming an issue while considering impact. | रूखापन |
| Receptive listening | ध्यान से सुनना | Use in public/result labels. “सक्रिय सुनना” may appear only in explanatory prose. | निष्क्रिय सुनना |
| Emotional transparency | भावनात्मक स्पष्टता | Use for the named dimension. | भावनात्मक पारदर्शिता |
| Collaborative inquiry | मिलकर जिज्ञासा | Use in public/result labels. | सहयोगी जिज्ञासा |
| Constructive assertion | स्पष्ट लेकिन सम्मानजनक आग्रह | Use in explanatory/result copy; shorten to “सम्मानजनक आग्रह” only where space is constrained. | रचनात्मक आग्रह, रचनात्मक दृढ़ता |
| Feedback exchange | प्रतिक्रिया का आदान-प्रदान | Use for the named dimension. | फीडबैक एक्सचेंज |
| Conflict navigation | मतभेद सँभालना | Use for the named dimension. | असहमति संभालना |
| Audience adaptability | श्रोता के अनुसार ढलना | Use for the named dimension. | ऑडियंस अडैप्टेबिलिटी |
| Decision alignment | निर्णय में सामंजस्य | Use for the named dimension. | निर्णय संरेखण |
| Mixed evidence | मिश्रित संकेत | Confidence label; avoid implying inconsistency is a flaw. | विरोधाभासी व्यक्तित्व |
| Limited evidence | सीमित संकेत | Use when more situations are needed. | पर्याप्त नहीं |
| Weekly Experiment | साप्ताहिक प्रयोग | Keep practical and non-therapeutic. | साप्ताहिक चुनौती |
| “Tone felt dismissive” | “उसे आपके बोलने के ढंग में उसकी बात को कम महत्व मिलने का एहसास हुआ।” | Contextual and less accusatory than “उपेक्षापूर्ण”. | तुम्हारा लहजा उपेक्षापूर्ण था |

## Context exceptions

“अपनी बात सम्मानपूर्वक रखना” may replace the full Constructive assertion label in a sentence that describes a behaviour, not the named dimension. “जगह” is preferred over “space” in relationship scenarios, while “निजी जगह” is used only where ambiguity could be harmful.
